## Probar
Abre `index.html` en Chrome, Edge o Firefox.

## Publicar en Render
1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En Render elige New + > Static Site.
3. Conecta el repositorio.
4. Deja Build Command vacío.
5. En Publish Directory coloca `.` (si index.html está en la raíz).
6. Publica. Render asignará una URL gratuita bajo onrender.com, sujeta a sus condiciones vigentes.

## Antes de publicar
Confirma nombre y disponibilidad de marca, tarifas, alcance, condiciones tributarias, correo comercial y política de privacidad.
El formulario prepara un mensaje y abre WhatsApp; no guarda datos en una base de datos.
Los periféricos se muestran como categorías bajo pedido, no como inventario disponible.

- `assets/whatsapp.svg`: icono vectorial de WhatsApp usado en los botones de contacto.

- `assets/whatsapp-brand.png`: icono de WhatsApp proporcionado para los botones de contacto.
